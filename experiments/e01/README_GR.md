# NOESIS E01 v0.1 — Εργαστήριο ανακάλυψης κανόνων

Πρώτος εκτελέσιμος ερευνητικός πυρήνας για το έργο NOESIS του Konstantinos Georgalas. Ημερομηνία: 30/09/2026.

## Το αποτέλεσμα με απλά λόγια

Σε 2.000 ζεύγη προβλημάτων, οι στοχευμένες δοκιμές χρειάστηκαν κατά μέσο όρο 8,8715 παρατηρήσεις αντί για 10,887: μείωση 18,51%. Είχαμε μηδενικές αποτυχίες εντός 16 δοκιμών και στις δύο μεθόδους. Η στοχευμένη επιλογή χρειάζεται περισσότερη εσωτερική επεξεργασία.

Αυτό είναι συγκεκριμένο αποτέλεσμα ενεργού μάθησης σε έναν μικρό, σχεδιασμένο κόσμο. Δεν είναι ακόμη νευρωνικό μοντέλο, chatbot, ανθρώπινο μυαλό ή σύστημα που δημιουργεί μόνο του νέες έννοιες. Δεν αποθηκεύει γνώση μεταξύ των προβλημάτων. Ο γενικότερος στόχος του NOESIS παραμένει ερευνητικός.

## Τι χρειάζεσαι

Python 3.10 ή νεότερο. Μόνο standard library: δεν χρειάζεται pip install, κλειδιά API, συνδρομή, GPU ή σύνδεση στο Internet για την εκτέλεση. Έχει ελεγχθεί στο Linux περιβάλλον της εκτέλεσης που καταγράφεται στο results/manifest.json. Δεν έχει γίνει φυσική δοκιμή σε Mac ή Windows· ο κώδικας δεν χρησιμοποιεί ειδικές λειτουργίες Linux.

Το πακέτο είναι κώδικας εργαστηρίου για Terminal, όχι έτοιμη εφαρμογή με γραφικό περιβάλλον.

## Mac — εκτέλεση

Αποσυμπίεσε το ZIP στο Downloads. Στο Terminal:

```bash
cd ~/Downloads/NOESIS_E01_v0.1
python3 -m noesis --demo
```

Η επίδειξη δείχνει ποιους διακόπτες δοκίμασε κάθε μέθοδος και πόσες υποθέσεις παρέμειναν μετά από κάθε παρατήρηση. Αποκαλύπτει τον κανόνα μετά το τέλος.

Για επανάληψη ολόκληρου του πειράματος:

```bash
python3 -m noesis --config config.json --out my_results
```

Ο φάκελος εξόδου πρέπει να μην υπάρχει. Αν το ξανατρέξεις, βάλε νέο όνομα, π.χ. `--out my_results_02`. Τα αποθηκευμένα αποτελέσματα δεν αντικαθίστανται.

Για τους 13 ελέγχους:

```bash
python3 -m unittest discover -s tests -v
```

## Windows — εκτέλεση

Άνοιξε PowerShell μέσα στον αποσυμπιεσμένο φάκελο:

```powershell
py -3 -m noesis --demo
py -3 -m noesis --config config.json --out my_results
py -3 -m unittest discover -s tests -v
```

## Τι υπάρχει στο πακέτο

- `noesis/core.py`: γεννήτρια 429 μοναδικών Boolean συναρτήσεων βάθους ≤2, περιβάλλον και δύο agents.
- `noesis/experiment.py`: αξιολόγηση χωρίς πρόσβαση του agent στον κρυφό στόχο, μετρικές και bootstrap ανά seed.
- `tests/test_core.py`: 13 έλεγχοι, περιλαμβανομένου ελέγχου διατήρησης αληθινής υπόθεσης για κάθε συνάρτηση της γραμματικής.
- `config.json`: οι ακριβείς ρυθμίσεις της παραδοθείσας εκτέλεσης.
- `results/REPORT_GR.md`: αναλυτική ελληνική αναφορά και όρια ερμηνείας.
- `results/manifest.json`: καταγραφή περιβάλλοντος και SHA-256 κώδικα πριν από το πείραμα.
- `results/episodes.jsonl`: 4.000 πλήρεις τροχιές, δηλαδή δύο μέθοδοι για 2.000 κοινά προβλήματα.
- `results/episodes.csv`, `results/summary.json`, `results/grammar.json`: συνοπτικά δεδομένα, αποτελέσματα και ο γνωστός χώρος υποθέσεων.
- `verify_results.py`: ανεξάρτητος έλεγχος των αποθηκευμένων τροχιών και βασικών αριθμών.

Οι 2.000 περιπτώσεις δεν είναι 2.000 διαφορετικοί κανόνες. Υπάρχουν επαναλήψεις μεταξύ seeds και συνολικά εμφανίστηκαν 428 διαφορετικές συναρτήσεις.

## Επιστημονική θέση

Το E01 είναι δική μας υλοποίηση ενός ελεγχόμενου πειράματος, όχι νέα ανακάλυψη. Η πολιτική χρησιμοποιεί τυπική επιλογή μέσω αναμενόμενου κέρδους πληροφορίας, με ομοιόμορφη posterior πάνω στις συμβατές υποθέσεις. Δεν αποτελεί αναπαραγωγή του DreamCoder ή του Dreamer και δεν χρησιμοποιεί κώδικά τους.

Η αρχική βιβλιογραφική κατεύθυνση του έργου περιλαμβάνει:

- DreamCoder — https://arxiv.org/abs/2006.08381
- Complementary learning systems within the hippocampus — https://pmc.ncbi.nlm.nih.gov/articles/PMC5124075/
- Mastering diverse control tasks through world models — https://doi.org/10.1038/s41586-025-08744-2

Οι πηγές είναι αφετηρίες για μεταγενέστερες μονάδες· δεν τεκμηριώνουν τα αριθμητικά αποτελέσματα αυτού του πειράματος. Τα αποτελέσματα προκύπτουν από τον παραδιδόμενο κώδικα και τα δεδομένα.

Επόμενο βήμα: E02, μάθηση από προηγούμενα προβλήματα με πραγματικό διαχωρισμό δομών εκπαίδευσης/αξιολόγησης. Δεν υλοποιείται ακόμη μνήμη μεταφοράς, replay ή δημιουργία νέων primitives.
