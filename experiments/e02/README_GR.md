# NOESIS E02 v0.2 — Μάθηση από προηγούμενη εμπειρία

Αυτόνομο πακέτο έρευνας για τον Konstantinos Georgalas, 30/09/2026. Δεν αντικαθιστά τον φάκελο του E01.

## Τι κάνει

Μαθαίνει από παρατηρήσεις προηγούμενων προβλημάτων ποιοι τύποι κανόνων εμφανίζονται συχνότερα. Αποθηκεύει αυτή τη στατιστική γνώση σε JSON και την χρησιμοποιεί ως αρχική πιθανότητα για να επιλέγει δοκιμές σε καινούργια προβλήματα. Όλα εκτελούνται τοπικά χωρίς APIs, λογαριασμούς, GPU, pip install ή πληρωμές.

Είναι μικρό σύστημα Bayesian ενεργού μάθησης, όχι ακόμη νευρωνικό δίκτυο ή chatbot. Δεν δημιουργεί μόνο του νέα χαρακτηριστικά/έννοιες. Το χαρακτηριστικό «πόσα outputs είναι 1» έχει επιλεγεί από εμάς. Οι συχνότητές του μαθαίνονται από την εμπειρία.

## Πραγματικό αποτέλεσμα

100 ανεξάρτητα seeds με διαφορετικούς διαχωρισμούς ομάδων. Ανά seed: 200 training και 40 validation προβλήματα, και 20 test προβλήματα για καθεμία από τρεις συνθήκες. Δύο agents ανά test πρόβλημα: σύνολο 6.000 ζεύγη / 12.000 εκτελέσεις.

| Νέα προβλήματα | Χωρίς εμπειρία | Με εμπειρία | Αποτέλεσμα εμπειρίας |
|---|---:|---:|---|
| Παρόμοια κατανομή | 8,920 | 8,658 | 2,94% λιγότερες δοκιμές |
| Αντίθετη κατανομή | 9,1315 | 9,751 | 6,78% περισσότερες δοκιμές |
| Ομοιόμορφη κατανομή | 8,8665 | 9,0735 | 2,33% περισσότερες δοκιμές |

Οι τιμές είναι μέσες πραγματικές παρατηρήσεις μέχρι ταυτοποίηση. Και οι δύο agents χρησιμοποιούν στοχευμένες δοκιμές: το νέο όφελος 2,94% δεν συγκρίνεται απευθείας με το 18,51% του E01, που συνέκρινε στοχευμένες με τυχαίες δοκιμές σε άλλη κατανομή.

Η προετοιμασία κοστίζει επιπλέον 3.840 πραγματικές παρατηρήσεις ανά seed. Δεν έχει αποδειχθεί καθαρή εξοικονόμηση στο συνολικό κόστος εκπαίδευσης και αξιολόγησης αυτού του μικρού run. Το όφελος αφορά τη φάση χρήσης μετά την προετοιμασία.

Πέρασαν 15 tests. Ανεξάρτητος έλεγχος επαλήθευσε 100 μοντέλα, 12.000 τροχιές, διαχωρισμούς, μαθημένες πιθανότητες, επιλογές validation, paired targets και hashes του κώδικα.

## Εκτέλεση σε Mac

Χρειάζεται Python 3.10 ή νεότερο. Αποσυμπίεσε στο Downloads και τρέξε:

```bash
cd ~/Downloads/NOESIS_E02_v0.2
python3 -m unittest discover -s tests -v
python3 -m noesis --config config.json --out mac_e02_results_01
```

Αυτό εκτελεί εκπαίδευση, επιλογή μέσω validation και αξιολόγηση. Θα εμφανίζει πρόοδο κάθε 10 seeds. Η δική μας εκτέλεση διήρκεσε περίπου 30 δευτερόλεπτα· ο χρόνος στο δικό σου μηχάνημα μπορεί να διαφέρει. Τα σταθερά αποτελέσματα είναι οι αριθμοί δοκιμών και οι μετρικές, όχι οι χρόνοι.

Αν ο φάκελος εξόδου υπάρχει ήδη, χρησιμοποίησε νέο όνομα, π.χ. `--out mac_e02_results_02`. Το πρόγραμμα αρνείται να αντικαταστήσει παλιό run.

Για επίδειξη που φορτώνει ήδη αποθηκευμένη εμπειρία:

```bash
python3 -m noesis --demo
```

Η επίδειξη χρησιμοποιεί το πρώτο seed και προκαθορισμένο test πρόβλημα, όχι παράδειγμα επιλεγμένο επειδή κερδίζει ο learned. Στο seed 0 το validation επέλεξε πλήρως ομοιόμορφη prior, επομένως οι δύο μέθοδοι ισοβαθμούν. Αυτό είναι αναμενόμενο. Σε 28 από τα 100 seeds προτιμήθηκε η πλήρης επιστροφή στην ομοιόμορφη prior, σε 55 η ανάμειξη 0.1 και σε 17 η ανάμειξη 0.5.

Μπορείς να φορτώσεις συγκεκριμένο άλλο μοντέλο:

```bash
python3 -m noesis --demo --model results/models/seed_001.json
```

Δεν εγγυάται καλύτερο αποτέλεσμα σε κάθε μεμονωμένο πρόβλημα. Το μοντέλο φορτώνεται από JSON, χωρίς επανεκπαίδευση.

## Windows

Άνοιξε PowerShell στον φάκελο του πακέτου και χρησιμοποίησε `py -3` αντί για `python3`:

```powershell
py -3 -m unittest discover -s tests -v
py -3 -m noesis --config config.json --out windows_e02_results_01
```

Το πακέτο ελέγχθηκε σε Linux. Δεν έχει ακόμη πραγματοποιηθεί δική σου δοκιμή E02 σε Mac ή φυσική δοκιμή Windows.

## Αρχεία

- `results/REPORT_GR.md`: αναλυτική αναφορά, διαστήματα αβεβαιότητας και περιορισμοί.
- `results/models/seed_*.json`: 100 αποθηκευμένες μαθημένες priors, training/validation εμπειρίες και διαχωρισμοί.
- `results/summary.json`: οι συγκεντρωτικές μετρικές και τα bootstrap διαστήματα ανά συνθήκη.
- `results/episodes.jsonl`: όλες οι test τροχιές.
- `results/manifest.json`: config, περιβάλλον και hashes κώδικα πριν από την εκπαίδευση.
- `results/grammar.json`: οι 429 συναρτήσεις που μπορεί να εξετάσει ο agent.
- `results/runtime.json`: χρόνος και κόστος προετοιμασίας.
- `verify_results.py`: ανεξάρτητος έλεγχος των παραδιδόμενων αποτελεσμάτων. Τρέχει με `python3 verify_results.py` και ελέγχει τον φάκελο `results`, όχι αυτόματα οποιοδήποτε νέο run.

Το CLI είναι ερευνητικό εργαλείο χωρίς γραφικό περιβάλλον. Δεν λειτουργεί στο παρασκήνιο και δεν αποκτά πρόσβαση σε άλλες εφαρμογές.

## Πώς συνδέεται με τον μεγαλύτερο στόχο

Το E01 δοκίμασε την επιλογή πληροφοριακών παρατηρήσεων. Το E02 δοκίμασε τη μεταφορά μιας μαθημένης στατιστικής προτίμησης. Η αντίθετη κατανομή έδειξε αρνητική μεταφορά: οι παλιές προσδοκίες καθυστερούν τη μάθηση. Αυτά είναι ελεγχόμενα αποτελέσματα σε γνωστή γραμματική, όχι απόδειξη αναπαραγωγής του ανθρώπινου μυαλού.

Η επόμενη ερευνητική απόφαση είναι πώς θα αντιλαμβάνεται ότι οι παλιές προσδοκίες δεν ταιριάζουν, χωρίς να γνωρίζει εκ των προτέρων την αλλαγή. Η αξιολόγηση ενός τέτοιου μηχανισμού χρειάζεται νέο πρωτόκολλο και νέα δεδομένα· δεν προστέθηκε μετά την εξέταση των παρόντων αποτελεσμάτων.
